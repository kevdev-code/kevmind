# Product

## Register

product

## Users

Developers who run Claude Code for hours and keep KevMind open beside it, usually on a second monitor or a narrow side window, often in a dim room late in the day. They glance at it between prompts rather than study it: is Claude working, waiting for me, or stuck; which agents are running in parallel; what just got read, edited or failed. The same people open the Memory tab occasionally, to check what Claude remembers about a project and fix what is broken there. The interface is bilingual (English and Spanish), and many users work on Windows.

## Product Purpose

KevMind makes Claude Code's work visible in real time: sessions, parallel agents, a live activity feed, files touched, tools used, token counts, conflicts between agents, and a read-only report on each project's memory and instruction files. It also gives Claude itself a history of the project through opt-in tools. Success is that the user knows what Claude is doing within a second of looking, trusts the numbers, and forgets the dashboard is running: it costs no attention when nothing happens and almost no CPU.

## Brand Personality

Calm, precise, quietly confident. The tone of a well-made instrument rather than a show: Linear's calm density and Raycast's restrained purple accent, with state colors as clear as GitHub Primer's, distinct at a glance and comfortable for long sessions. Copy is short, literal and plain in both languages.

## Anti-references

- Neon "AI dashboard": glows, gradients, glassmorphism, purple haze. Glows and gradients are reserved for the future, optional brain view, never the everyday panels.
- Grafana wall: every panel at the same volume, chart overload.
- SaaS admin template: identical cards, big hero numbers with tiny labels, generic icon tiles.
- Hacker terminal: green on black, monospace everywhere, retro CRT. Monospace is for paths, commands and file names only.

## Design Principles

- **Glanceable first.** The question "what is Claude doing right now, and does it need me?" is answered by the strongest element on the screen; everything else steps back.
- **Color means state.** Accent and semantic colors mark status, selection and kinds of work, never decoration. Two things share a color only if they mean the same thing.
- **Quiet when idle.** Motion only for a real change (an active agent, a new event), and nothing moves, repaints or spends CPU when nothing happens.
- **Honest numbers.** Counts, dates and tokens are exact and labeled, never estimated for effect; empty and "not yet" states say what is missing.
- **Same vocabulary everywhere.** Live and Memory share one set of surfaces, type steps, controls and state colors.

## Accessibility & Inclusion

WCAG 2.2 AA contrast in both dark and light themes, including muted text and state colors used as text. State is never conveyed by color alone (a word or shape accompanies it). `prefers-reduced-motion` is respected everywhere. Every control is keyboard-reachable with a visible focus ring. Spanish strings run longer than English and must fit without truncating meaning, and the layout works at phone width.
